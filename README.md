# GoGitIt

Fresh open-source GitHub projects every day, each with a plan to turn it into a small business: what it does, who it's for, ideas, what a buyer gets, what to charge, and where to find leads.

- Fetches 100 new repos a day (games, utilities, everyday tools, tech) and never repeats one.
- Open-source licenses only.
- Filter by what you could build from a repo: web app, website, mobile app, desktop app, browser extension, bot or automation, API or backend.
- Saved in your browser. Star a repo to add it to your wishlist.
- Share any repo: on your phone it opens the share sheet (text, WhatsApp, email and so on); on a computer it copies the repo, a business idea and the link to your clipboard.
- Optional GitHub token in Settings for faster fetching.
- Sync across devices through a private gist in your own GitHub account (Settings, token with gist permission, turn on sync).

Open `index.html` in a browser, or turn on GitHub Pages (Settings, Pages, deploy from `main` / root) to use it on your phone.
